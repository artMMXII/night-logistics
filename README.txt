НОЧНАЯ ЛОГИСТИКА — PWA

Состав:
- index.html, styles.css, app.js — приложение
- manifest.webmanifest — параметры установки
- sw.js — автономная работа после первой загрузки
- icon.svg — значок

Функции:
- 15 отделов;
- отдельный ввод прихода и отзывов;
- автоматический подсчёт;
- формирование текста для рабочего чата;
- нулевые отделы скрыты по умолчанию (есть переключатель);
- автосохранение на устройстве через localStorage;
- очистка данных текущей смены.

ВАЖНО:
Для установки как PWA нужен HTTPS-хостинг. Для локальной проверки можно открыть index.html,
но установка на главный экран и офлайн-кэш в таком режиме могут не работать.

Рекомендуемый способ публикации:
1. Создать репозиторий на GitHub.
2. Загрузить в него все файлы из этой папки.
3. В Settings -> Pages выбрать Deploy from a branch, ветку main и папку /(root).
4. Открыть выданный HTTPS-адрес на телефоне.
5. Android/Chrome: меню браузера -> Установить приложение или Добавить на главный экран.
   iPhone/Safari: Поделиться -> На экран «Домой».

Данные хранятся только в браузере конкретного телефона. Они не синхронизируются между устройствами.
Не нажимайте «Очистить» до копирования отчёта в рабочий чат.
